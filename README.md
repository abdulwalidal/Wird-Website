# Wird

**Your habits, anchored to prayer.**

Wird is an Islamic habit tracker for Android built around one idea: the Prophet ﷺ had a daily routine, and every Muslim can follow it. Every habit in the app has a hadith behind it. Every dhikr has a source. Scheduled around all six prayer times — not a clock. Fully offline, no account, no ads.
